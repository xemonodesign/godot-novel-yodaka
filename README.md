# よだか — ことばの標本

Godot 4.6.2 製のノベルゲーム・プロトタイプ。2026-09-25更新。

**遊ぶ:** https://xemonodesign.github.io/godot-novel-yodaka/

## プロトの流れ（2026-09-25版）

1. **冒頭のカウンセリング**：台本「カウンセリング0（OP）」と「カウンセリング1（システムチュートリアル）」を収録。カウンセラーのみなとが法月よだかに「メンタル〇〇」アプリを渡し、3つの質問（クラスでの反応・学校のハードル・はじめてのバイト）にそれぞれ3択で答えます。答えた瞬間にパラメータが動き、カルテで現在の状態を見ます。
2. **どこに行くか選ぶ寄り道（MAP）**：断片集1・2の全17編＋「家で休む」から1つ選び、その場所の会話を再生。会話中に言葉をもらうと、**その場で**パラメータが変化します（「あ、何かあったんだ」の手応え）。他人の言葉が出てこない独白の断片は、読み終えた時の気づきとしてパラメータが少し動きます。行き先は週ごとに増えます（第1週7か所、第2週+5、第3週+5）。
3. **夜（言葉を育てる）**：寄り道や本編のあとは毎回、部屋で集めた言葉をひとつ選び「嬉しかった／自分らしくない／まだわからない」から受け取り方を決めます。言葉が育って標本に結晶がつき、パラメータが大きく動きます。育てても育てなくても最後は眠り、ストレスが少し下がります。
4. **メインストーリー**：寄り道を各週3回こなすと本編 CHAPTER 1〜4（原稿メイン01〜04）が解放され、②〜③を繰り返します。17か所のうち12回を選ぶので、1周では行けない場所が残ります。
5. **総括のカウンセリング**：4章を終えるとみなとが数週間を振り返ります。夜に育てた言葉はよだかがそのまま自分の言葉として伝え、育てていない言葉はここで受け取り方を選びます。最後にカルテを見て終了（END OF PROTOTYPE）。

## パラメータ

ストレス + 3種類（勇気・自認・キラキラ）の4つ。初期値は `[60, 35, 35, 35]`。

- **ストレス**：出かけると +5、本編の章が始まると +6（社交の筋肉痛）。眠ると毎晩 -4、「家で休む」で -15。80以上になると寄り道に出かけられず、休むしかありません。
- **勇気**：CHAPTER 4「お姫様じゃなくてもいい」の選択に60必要。言葉の取得と夜の成長で貯めます。
- **自認**：自分の捉え方への納得度という暫定指標。男女を数値の両端にはしていません。
- **キラキラ**：人前での輝き。あしかとの本編で動きやすい指標。

言葉は13種類（原稿の10語＋断片集2の「あす、あす」「付き合ってあげる」「宇宙の破滅」）。言葉ごとに「もらった時の即時効果」と「育てた時の3通りの効果」を持ち、1回に動くのは最大2項目。選ぶ前に増減値と上限・下限を表示します。

## 操作

- 画面をクリック、または Space / Enter：全文表示、もう一度で次の文章。
- 章・場所の切り替え、言葉をもらった時の暗転、カルテはクリック / タップで進みます。AUTOやSpaceでは飛ばしません。
- 選択肢：クリック / タップして選択。効果の予告が下に出ます。AUTO は選択肢で止まります。
- MAP：18個の行き先ボタンから選択。行った場所・まだ解放されていない場所・疲れて行けない場所は理由つきで無効になります。
- 夜：標本をクリック → 受け取り方を選ぶ → 眠る。育てずに眠ることもできます。
- 下の標本：クリックすると、誰にもらった言葉か、もらった時の変化、受け取り方を読み返せます。★は育てた言葉。
- 「読み返す」で会話ログ、「文字速度」で表示速度、「カルテ」で4つの指標の説明を表示。
- 同じブラウザ・同じURLで自動保存。「つづきから」で再開します。以前の流れ（v3以前）の保存は読み込まず、「はじめから」で新しい流れを遊びます。
- PC / 横向きの画面向けです。小さい画面では全体を縮小して表示します。

## 実装

- 中央揃えの文字送り、全文表示、AUTO、会話ログ、速度変更、自動保存（形式v4）。
- 章・場所の切り替えに暗転し、中央に章名と場所を表示。カウンセリングは COUNSELING、寄り道は AFTER SCHOOL、本編は CHAPTER。
- 言葉の取得時に暗転し、3D標本・光の粒・波紋と**その場の増減値**を表示。クリックで続行。
- 夜の画面で言葉を選ぶと3つの受け取り方と増減予告を表示。育てた標本は明るく大きくなり結晶がつきます。
- MAPは3×6の格子で18か所を表示し、週ごとに寄り道の残り回数と次の章を表示。行き先は週（unlock）・訪問済み・ストレスで制御。
- 断片集1の10編には題名が無いため、プロト用に題名（手を繋ぐ相手・雨除けカバー・友達親子・季節はずれの風鈴・傘のユニコーン・歩道橋の夕焼け・透明な人の夢・カラオケの割引券など）を付けています。
- カウンセリング1の3択は台本の「選択肢」「〜を選択」「選択肢差分終了」の行から自動で分岐を構築。
- よだかを右、会話相手（みなと・りあ・あしか・すみか）を左に同サイズで配置。話者を明るく、聞き手を暗く表示。
- 教室・廊下・自宅・ファミレス・喫茶店・自然公園・街・診察室の背景を場所で切り替え。

元の台本はローカルに保持し、公開物にはゲームに必要な素材とデータを含めています。ゲームで使うメイン4シート＋断片17シート＋カウンセリング2シートの本文は `src/data/source_rows.json` に行単位でキャッシュし、元のXLSXがなくても `make import` と `make test` が動きます（`scenario.json` と同じ本文のみ）。「家で休む」の3行だけはプロトタイプ用に追加した文章です。すみかは既存の `girl.png` を仮使用し、`images/character/sumika.png` があれば優先します。音声・BGMは未実装です。

## 開発

Godot 4.6.2 と同バージョンの Export Templates を使います。

```sh
make install
make run
make lint
make test
make web
make serve
```

`make serve` の後、http://localhost:8060 を開きます。Web出力は `build/web/`。HTMLをダブルクリックして開く方式では動きません。`make web` は生成済みの `src/data/scenario.json` を使用するので、公開リポジトリだけでもビルドできます。

### 台本・言葉を変更する

1. 元のXLSX（メイン・断片集1・断片集2・カウンセリング）をプロジェクト直下に置きます。無い本は `src/data/source_rows.json` のキャッシュから読みます。
2. `src/data/word_marks.json` の `node`（シート別ID＋行番号）と `word`（原文内の文字列）を指定します。
3. `make import` でXLSXから `scenario.json` を再生成。使ったシートの本文がキャッシュにも書き戻されます。
4. `make test` → `make web`。

`model` は `flower` / `rock`、`color` は16進色、`effects` はもらった時の即時効果、`memory` はよだかが話す出来事、`interpretations` は3つの受け取り方です。各受け取り方の `label` は選択肢、`reply` はよだかの返答、`effects` は最大2つのステータス名と増減値です。ストレスの出費・回復は `src/story_state.gd` の `OUTING_EFFECTS` `CHAPTER_EFFECTS` `SLEEP_EFFECTS`、休息の回復は `REST_LINES` 末尾の `effects`。周回の構成（寄り道の回数と章）は `src/tools/import_scenario.py` の `ROUNDS`、行き先の題名・場所・相手・解放週・独白の気づき効果は `EVENTS`、チュートリアルの選択効果は `TUTORIAL_EFFECTS`、勇気の必要値は `COURAGE_GATE` で変更し、`make import` で反映します。

### 公開の更新

`gh-pages` ブランチのルートをGitHub Pagesの配信元にしています。

```sh
make web
git worktree add /tmp/yodaka-pages gh-pages
cp build/web/* /tmp/yodaka-pages/
touch /tmp/yodaka-pages/.nojekyll
git -C /tmp/yodaka-pages add .
git -C /tmp/yodaka-pages commit -m 'feat(web): update playable prototype'
git -C /tmp/yodaka-pages push origin gh-pages
```

既に作業ツリーがあればそのパスを再利用してください。ソース変更は `main` に通常どおりコミットします。

詳細は [構成](docs/architecture.md) と [素材・生成記録](docs/assets.md) を参照。

ブラウザ検証: Playwrightをインストールした環境で `node tests/browser_smoke.cjs`。`YODAKA_URL` で対象URL、`YODAKA_CHROMIUM` でChromiumの実行ファイルを指定でき、専用の一時ブラウザ内で通しプレイ・チュートリアルの効果・ストレスによる外出制限・勇気の分岐・総括の返答を検証します。
