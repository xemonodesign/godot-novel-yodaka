# よだか — ことばの標本

Godot 4.6.2 製のノベルゲーム・プロトタイプ。2026-10-19更新。

**遊ぶ:** https://xemonodesign.github.io/godot-novel-yodaka/

## プロトの流れ（2026-10-19版）

1. **冒頭のカウンセリング**：台本「カウンセリング0（OP）」と「カウンセリング1（システムチュートリアル）」を収録。3つの質問に3択で答えるとパラメータが動き、カルテで現在の状態を見ます。そのあと**最初のセッション**に入り、心の棚に刺さった8つのトラウマから、話しやすいひとつを選んでみなとに話します（解きほぐし）。最初のひとつだけは向き合うのに必要なEXPが30まで下がるので、その場で向き合って棚に枠をひとつ空けられます。
2. **自由行動（MAP）**：地図のピンから行き先を選びます。会話を1タップ進めるごとに **EXP +1**（言葉の効果で倍増）。言葉をもらうと、その場で**心に留める**か**手放してEXPにする**かを選びます。棚に空き枠が無ければ、留めている言葉のどれかを手放す必要があります。
3. **夜**：背景が暗くなる夜のオープニングのあと、今日のEXPと棚の様子を確認して眠ります。眠るとストレスが下がります（トラウマで半減することも）。
4. **メインストーリー**：自由行動を各週3回こなすと本編 CHAPTER 1〜4 が解放されます。CHAPTER 1 と 3 のあとは**カウンセリング**（2回目・3回目）、CHAPTER 4 のあとは**総括のカウンセリング**（4回目）。
5. **カウンセリング**：心の棚を広げた盤面で、以下ができます。
   - **トラウマを話す**（1セッションに1つ）：みなとに話すだけで強さ −20。留めている言葉を2つまで持ち込むと、言葉ごとの「強さ −N」「必要EXP ×0.5 / ×0.1」が重なります。持ち込んだ言葉は使い切り。トラウマと同じ種類（居場所・身体・恋・家族・過去）の言葉は**響いて効果2倍**。数値が減るエフェクトと一緒に、回想→みなとの受け止め→よだかの気づきの会話が流れます。
   - **向き合う**：ほぐれたトラウマは、必要EXP（元の必要量 × 残りの強さ）を払うと棚から消え、枠が空きます。棚のカードからいつでも実行できます。
   - **言葉を掘り下げる**：留めている言葉にEXPを使うと Lv2（3つの受け取り方から選んで、よだかが語る）→ Lv3（「こういう意味だったのか」の気づき）に育ちます。Lv1では勇気+1しかない「奇跡」が、Lv3では**1タップのEXPが10倍・必要EXP 1/10**になるなど、最初のザコいカードほど化けます。
   - **変身するボス**：トラウマによっては、強さ30以下までほぐすと奥から**もっとエグい言葉**（強さ150・必要EXP 200,000など）が出てきて、その枠に居座ります。ほぐし切る前にEXPを払って向き合うか、それとも奥まで踏み込むかが悩みどころ。
6. **総括**：4回目のセッションを終え、カルテを見て終了（END OF PROTOTYPE）。

## 心の棚・トラウマ・EXP

- 棚は8枠。最初は全部トラウマで埋まっています。トラウマは枠を塞ぐだけでなく、常にデバフを出します（弱らせると小さくなり、向き合うと消えます）。
- EXP は会話を1タップ進めるごとに +1（初めて読む行だけ）。留めている言葉の「1タップのEXP ×N」が掛かります。言葉を手放したときも言葉ごとのEXPが入り、「手放す言葉のEXP ×20」の言葉を持っていれば20倍になります。
- 最初に解きほぐしたトラウマだけ必要EXPが30。ほかは 1,500〜20,000、奥から出てくるものは 120,000〜200,000 と法外な量なので、言葉の「必要EXP ×0.1」や「強さ −80」を重ねて減らします。

| トラウマ | 誰の言葉 | 種類 | デバフ | 向き合うEXP |
|---|---|---|---|---|
| どう扱えばいい？ | クラスの空気 | 居場所 | キラキラ半減 | 3,000 |
| もう男じゃないんだし | 昔のチームメイト | 身体 | 勇気の上限5（CHAPTER 4 の選択に必要な15に届かない） | 20,000 → 奥に「本当は、自分でもそう思ってる」（200,000） |
| 普通にしてよ | 元恋人 | 恋 | ストレス常時+8 | 8,000 → 奥に「じゃあ、どうしたかったの？」（120,000・ストレス+20） |
| 女の子がほしかったの | 母 | 家族 | 「家で休む」の回復が半分 | 5,000 |
| 使用感アリ　値引き | メルカリの画面 | 過去 | 手放した言葉のEXPが半分 | 2,000 |
| バイト仲間じゃん？ | バイト先の先輩 | 居場所 | もらった言葉の変化が半分 | 1,500 |
| 留年までして | 親戚 | 過去 | 眠っても回復が半分 | 4,000 |
| 声、女の子だね | クラスメイト | 身体 | 自認半減 | 2,500 |

言葉（カード）の効果一覧は [docs/words.md](docs/words.md)。

## パラメータ

ストレス + 3種類（勇気・自認・キラキラ）の4つ。初期値は `[60, 5, 5, 5]`。画面に出るのは**トラウマと言葉を反映した値**で、素の値と違うときは ▴▾ を添え、カルテに「（素 n）」で併記します。外出できるかどうか（ストレス80）や勇気の分岐（15）も反映後の値で判定します。

- **ストレス**：出かけると +5、本編の章が始まると +6。眠ると毎晩 -4、「家で休む」で -15。80以上になると寄り道に出かけられません。
- **勇気**：CHAPTER 4「お姫様じゃなくてもいい」の選択に15必要。「もう男じゃないんだし」が残っている間は上限5。
- **自認**：自分の捉え方への納得度という暫定指標。
- **キラキラ**：人前での輝き。

## 操作

- 画面をクリック、または Space / Enter：全文表示、もう一度で次の文章。1タップごとに左下のEXPが増えます。
- 章・場所の切り替えの暗転、カルテはクリック / タップで進みます。言葉をもらった暗転は「心に留める」「手放す」のどちらかを選ぶまで閉じません。
- MAP：地図上のピンをクリックして出発。ストレスが80以上の日は「家で休む」だけ。
- 夜：「眠る」で次へ。
- カウンセリングの盤面：棚のカードをクリック → 右の詳細で「みなとに話す」「向き合う」「掘り下げる」「手放す」。持ち込む言葉はチェックで選びます。「今日は、ここまで」で終了。
- 下の棚：トラウマをクリックすると元の言葉・デバフ・強さ・向き合うボタン、言葉をクリックすると元の台詞・効果・手放すボタン。
- 左下の「いまの輪郭」：クリックでカルテ（4つの指標、EXP、刺さっている言葉、ことばの地図）。
- 「読み返す」「文字速度」「タイトル」は従来どおり。同じブラウザで自動保存（形式v5）。以前の形式の保存は読み込まず、「はじめから」で遊びます。

## 実装

- 中央揃えの文字送り、全文表示、AUTO、会話ログ、速度変更、自動保存（形式v5）。
- 心の棚（8枠）の描画。トラウマは暗い「トゲ」の標本で、残りの強さに応じてトゲが増減。言葉は従来の花・石の標本に Lv を表示。
- 言葉の取得時の暗転に「心に留める／手放す」の選択、棚が満杯なら入れ替え候補を表示。
- カウンセリングの盤面（棚・詳細・持ち込む言葉・予告・話す／向き合う／掘り下げる／手放す）と、話したときの数値減少エフェクト、奥から出てくる言葉の演出。
- デバフを反映した `effective_stats()` をメーター・MAP・選択肢の判定に使用。
- 台本の分岐・立ち絵・背景などは従来どおり。音声・BGMは未実装。

## 開発

Godot 4.6.2 と同バージョンの Export Templates を使います。

```sh
make install
make run
make lint
make test
make web
make serve
```

`make serve` の後、http://localhost:8060 を開きます。Web出力は `build/web/`。HTMLをダブルクリックして開く方式では動きません。`make web` は生成済みの `src/data/scenario.json` を使用するので、公開リポジトリだけでもビルドできます。

### 台本・言葉・トラウマを変更する

1. 元のXLSX（メイン・断片集1・断片集2・カウンセリング）をプロジェクト直下に置きます。無い本は `src/data/source_rows.json` のキャッシュから読みます。
2. `src/data/word_marks.json` の `node`（シート別ID＋行番号）と `word`（原文内の文字列）を指定します。
3. `src/data/traumas.json` でトラウマを編集します。
4. `make import` でXLSXから `scenario.json` を再生成。使ったシートの本文がキャッシュにも書き戻されます。
5. `make test` → `make web`。

言葉：`model` は `flower` / `rock`、`color` は16進色、`tag` は種類（トラウマと同じ種類なら響いて2倍）、`forget` は手放したときのEXP、`effects` はもらった時の即時効果、`memory` はよだかが話す出来事、`interpretations` は Lv2 で選ぶ3つの受け取り方（`label` 選択肢、`reply` よだかの返答、`effects` 最大2つの増減）。`levels` は Lv1〜3 の `cost`（そのLvに上げるEXP）、`hold`（持っているときの効果：ステータス名の増減、`exp_mult`、`forget_mult`）、`release`（話に持ち込んだときの `weaken`、`cost_mult`）、Lv3 の `insight`（気づきの台詞）。

トラウマ：`word` `speaker` `tag` `color`、`strength`（初期の強さ）、`cost`（向き合うEXPの元の量）、`debuff`（`half` / `cap` / `plus` はステータス指定、`rest_half` / `forget_half` / `gain_half` / `sleep_half` は強さが半分を切ると消える）、`deeper`（ほぐし切ると出てくるトラウマのID）、`quote` `recall` `doctor` `loosen` `resolve`（会話。本文領域に収まるよう1行26文字・3行まで、`doctor` は2行まで）。奥から出てくるものは `hidden: true` と `emerge`（出てきたときの台詞）を持ちます。

数値のルールは `src/story_state.gd` の定数（`EXP_PER_TAP` `FIRST_FACE_COST` `TALK_WEAKEN` `RESONANCE` `DEEPER_AT` `MAX_CARDS`、ストレスの `OUTING_EFFECTS` `CHAPTER_EFFECTS` `SLEEP_EFFECTS`）。周回の構成（寄り道の回数・章・そのあとにカウンセリングを挟むか）は `src/tools/import_scenario.py` の `ROUNDS`、行き先は `EVENTS`、チュートリアルの選択効果は `TUTORIAL_EFFECTS`、勇気の必要値は `COURAGE_GATE` で変更し、`make import` で反映します。

### 公開の更新

`gh-pages` ブランチのルートをGitHub Pagesの配信元にしています。

```sh
make web
git worktree add /tmp/yodaka-pages gh-pages
cp build/web/* /tmp/yodaka-pages/
touch /tmp/yodaka-pages/.nojekyll
git -C /tmp/yodaka-pages add .
git -C /tmp/yodaka-pages commit -m 'feat(web): update playable prototype'
git -C /tmp/yodaka-pages push origin gh-pages
```

既に作業ツリーがあればそのパスを再利用してください。ソース変更は `main` に通常どおりコミットします。

詳細は [構成](docs/architecture.md)、[素材・生成記録](docs/assets.md)、[拾える言葉の一覧](docs/words.md) を参照。

ブラウザ検証: Playwrightをインストールした環境で `node tests/browser_smoke.cjs`。`YODAKA_URL` で対象URL、`YODAKA_CHROMIUM` でChromiumの実行ファイルを指定でき、専用の一時ブラウザ内で通しプレイ（4回のセッションで話す・向き合う・言葉を留める／手放す）、言葉の取得時の選択、チュートリアルの効果、トラウマ込みのストレスによる外出制限、勇気の上限による分岐の封鎖、盤面での持ち込みと掘り下げを検証します。
