# よだかガールズモード（仮）

Godot 4.6.2 製のノベルゲーム・プロトタイプ。2026-10-20更新。

**遊ぶ:** https://xemonodesign.github.io/godot-novel-yodaka/

## プロトの流れ（2026-10-20版）

1. **冒頭のカウンセリング**：台本「カウンセリング0（OP）」と「カウンセリング1（システムチュートリアル）」を収録。3つの質問に3択で答えるとパラメータが動き、カルテで現在の状態を見ます。そのまま**最初のセッション**に入り、みなとが「棚にある言葉をひとつ選んで」と促すので、下の**心の棚**から謎のトラウマをひとつクリックして話します（開くのに少しEXPが要ります）。
2. **自由行動（MAP）**：地図のピンから行き先を選びます。会話を1タップ進めるごとに **EXP +1**（言葉の効果で倍増）。場所が変わるときは上の枠だけが暗転します。言葉をもらうと、その場で**心に留める**か**手放してEXPにする**かを選びます（空き枠が無ければ、留めている言葉のどれかと入れ替え）。
3. **メインストーリー**：自由行動を各週3回こなすと本編 CHAPTER 1〜4 へ。夜のパートは無く、日が終わるとそのまま次の場所へ進みます（**毎晩の回復はありません**。ストレスは「家で休む」で下げます）。CHAPTER 1 と 3 のあとは**カウンセリング**（2回目・3回目）、CHAPTER 4 のあとは**総括のカウンセリング**（4回目）。
4. **カウンセリング**：診察室の画面のまま、下の棚がハイライトされます。棚の項目にマウスを乗せると画面の真ん中に結晶が出て、何ができるか・必要なEXPが見えます。クリックでみなとに話します。
   - **謎のトラウマ**（暗いドロドロの枠）→ 話すと開いて**鑑定済み**になり、トゲトゲの結晶と言葉の中身が見えます（1セッションに1つ。開くと影響が強くなる場合があります）。
   - **鑑定済みのトラウマ** → 向き合うには法外なEXPが必要。持っている言葉の「向き合うEXP ×0.5」などが自動で掛かり（同じ種類の言葉は2回掛かる）、払えればクリックで向き合えてイベント会話。受け入れたトラウマは消え、枠が空きます。この体験版ではひとつ向き合えれば上出来の配分です。
   - **留めている言葉** → EXPを使って強化（Lv2 で受け取り方を選んでよだかが語る、Lv3 で「こういう意味だったのか」の気づき）。Lv1 では勇気+1しかない「奇跡」が、Lv3 では**1タップのEXP ×10・向き合うEXP ×0.1**になります。
   - 「今日は、ここまで」でセッション終了。
5. **総括**：4回目のセッションを終え、カルテを見て終了（END OF PROTOTYPE）。

## 心の棚・トラウマ・EXP

- 棚は8枠。最初は6つが謎のトラウマで埋まり、2枠が空いています。トラウマは3つの状態を取ります。
  - **謎**：暗くドロドロした枠。中身は見えないが、デバフはかかっている。開くのにEXP（20〜60）。
  - **鑑定済み**：トゲの結晶と言葉が見える。デバフはより強く。向き合うのに法外なEXP。
  - **受け入れた**：EXPを払って消えた状態。棚の空きとして使える。
- EXP は会話を1タップ進めるごとに +1（初めて読む行だけ）。留めている言葉の「1タップのEXP ×N」が掛かります。言葉を手放したときも言葉ごとのEXPが入り、「手放すEXP ×20」の言葉を持っていれば20倍。

| トラウマ | 誰の言葉 | 種類 | 謎のあいだ | 鑑定済み | 開く | 向き合う |
|---|---|---|---|---|---|---|
| どう扱えばいい？ | クラスの空気 | 居場所 | キラキラ 25%減 | キラキラ半減 | 30 | 3,000 |
| もう男じゃないんだし | 昔のチームメイト | 身体 | 勇気の上限12 | 勇気の上限5（CHAPTER 4 の選択に必要な15に届かない） | 60 | 20,000 |
| 普通にしてよ | 元恋人 | 恋 | ストレス常時+4 | ストレス常時+12 | 50 | 8,000 |
| 女の子がほしかったの | 母 | 家族 | 「家で休む」の回復が半分 | 同じ | 40 | 5,000 |
| 使用感アリ　値引き | メルカリの画面 | 過去 | 手放した言葉のEXPが半分 | 同じ | 25 | 2,000 |
| バイト仲間じゃん？ | バイト先の先輩 | 居場所 | もらった言葉の変化が半分 | 同じ | 20 | 1,500 |

言葉（カード）の効果一覧は [docs/words.md](docs/words.md)。例：「女王」（居場所・×0.5）と「付き合ってあげる」（×0.5）を持っていると「バイト仲間じゃん？」は 1,500 × 0.25 × 0.5 ＝ 188 EXP で向き合えます。

## パラメータ

ストレス + 3種類（勇気・自認・キラキラ）の4つ。初期値は `[60, 5, 5, 5]`。画面に出るのは**トラウマと言葉を反映した値**で（最初は `[64, 5, 5, 4]`）、外出できるかどうか（ストレス80）や勇気の分岐（15）も反映後の値で判定します。

- **ストレス**：出かけると +5、本編の章が始まると +6。回復は「家で休む」の -15 だけ（謎のうちから半減）。80以上になると寄り道に出かけられません。
- **勇気**：CHAPTER 4「お姫様じゃなくてもいい」の選択に15必要。「もう男じゃないんだし」を受け入れるまで上限がかかります。
- **自認**：自分の捉え方への納得度という暫定指標。
- **キラキラ**：人前での輝き。

## 操作

- 画面をクリック、または Space / Enter：全文表示、もう一度で次の文章。1タップごとに左下のEXPが増えます。
- 章・場所の切り替えは上の枠だけが暗転し、クリックで進みます。言葉をもらった暗転は「心に留める」「手放す」のどちらかを選ぶまで閉じません。
- MAP：地図上のピンをクリックして出発。ストレスが80以上の日は「家で休む」だけ。
- カウンセリング：棚の項目にマウスオンで内容と必要EXP、クリックでみなとに話す（開く／向き合う／強化）。「今日は、ここまで」で終了。
- 下の棚：カウンセリング以外のときにクリックすると、言葉の元の台詞と効果・手放すボタン、鑑定済みトラウマの元の言葉と影響が読めます。謎のままのトラウマは中身が見えません。
- 左下の「いまの輪郭」：クリックでカルテ（4つの指標とことばの地図）。
- 「読み返す」「文字速度」「タイトル」は従来どおり。同じブラウザで自動保存（形式v6）。以前の形式の保存は読み込まず、「はじめから」で遊びます。

## 実装

- 中央揃えの文字送り、全文表示、AUTO、会話ログ、速度変更、自動保存（形式v6）。
- 心の棚（8枠）の描画。謎のトラウマは暗い赤紫のマダラ（`goo.gd`）、鑑定済みはトゲの標本、言葉は花・石の標本。ツールチップや番号は出しません。
- マウスオンで枠の中央に出るプレビュー（結晶・言葉・必要EXP・できること）。
- 言葉の取得時の暗転に「心に留める／手放す」の選択、棚が満杯なら入れ替え候補を表示。
- カウンセリングは会話画面のまま棚を操作する方式。開いたときの結晶の出現、向き合ったときのよだかとみなとの会話、強化の会話。
- 場所の切り替えは上の枠（ボタン列より上）だけを暗転。
- デバフを反映した `effective_stats()` をメーター・MAP・選択肢の判定に使用。
- 台本の分岐・立ち絵・背景などは従来どおり。音声・BGMは未実装。

## 開発

Godot 4.6.2 と同バージョンの Export Templates を使います。

```sh
make install
make run
make lint
make test
make web
make serve
```

`make serve` の後、http://localhost:8060 を開きます。Web出力は `build/web/`。HTMLをダブルクリックして開く方式では動きません。`make web` は生成済みの `src/data/scenario.json` を使用するので、公開リポジトリだけでもビルドできます。

### 台本・言葉・トラウマを変更する

1. 元のXLSX（メイン・断片集1・断片集2・カウンセリング）をプロジェクト直下に置きます。無い本は `src/data/source_rows.json` のキャッシュから読みます。
2. `src/data/word_marks.json` の `node`（シート別ID＋行番号）と `word`（原文内の文字列）を指定します。
3. `src/data/traumas.json` でトラウマを編集します。
4. `make import` でXLSXから `scenario.json` を再生成。使ったシートの本文がキャッシュにも書き戻されます。
5. `make test` → `make web`。

言葉：`model` は `flower` / `rock`、`color` は16進色、`tag` は種類（トラウマと同じ種類なら割引が2回掛かる）、`forget` は手放したときのEXP、`effects` はもらった時の即時効果、`memory` はよだかが話す出来事、`interpretations` は Lv2 で選ぶ3つの受け取り方（`label` 選択肢、`reply` よだかの返答、`effects` 最大2つの増減）。`levels` は Lv1〜3 の `cost`（そのLvに上げるEXP）、`hold`（持っているときの効果：ステータス名の増減、`exp_mult`、`forget_mult`、`cost_mult`）、Lv3 の `insight`（気づきの台詞）。

トラウマ：`word` `speaker` `tag` `color`、`appraise`（開くEXP）、`cost`（向き合うEXPの元の量）、`debuff`（`half` / `cap` / `plus` はステータス指定で `mystery`＝謎のあいだの値と `value`＝鑑定済みの値、`rest_half` / `forget_half` / `gain_half` は棚にある限り有効）、`quote` `recall` `doctor` `resolve` `response`（会話。本文領域に収まるよう1行26文字・3行まで）。

数値のルールは `src/story_state.gd` の定数（`EXP_PER_TAP` `RESONANCE`、ストレスの `OUTING_EFFECTS` `CHAPTER_EFFECTS`）。周回の構成（寄り道の回数・章・そのあとにカウンセリングを挟むか）は `src/tools/import_scenario.py` の `ROUNDS`、行き先は `EVENTS`、チュートリアルの選択効果は `TUTORIAL_EFFECTS`、勇気の必要値は `COURAGE_GATE` で変更し、`make import` で反映します。

### 公開の更新

`gh-pages` ブランチのルートをGitHub Pagesの配信元にしています。

```sh
make web
git worktree add /tmp/yodaka-pages gh-pages
cp build/web/* /tmp/yodaka-pages/
touch /tmp/yodaka-pages/.nojekyll
git -C /tmp/yodaka-pages add .
git -C /tmp/yodaka-pages commit -m 'feat(web): update playable prototype'
git -C /tmp/yodaka-pages push origin gh-pages
```

既に作業ツリーがあればそのパスを再利用してください。ソース変更は `main` に通常どおりコミットします。

詳細は [構成](docs/architecture.md)、[素材・生成記録](docs/assets.md)、[拾える言葉の一覧](docs/words.md) を参照。

ブラウザ検証: Playwrightをインストールした環境で `node tests/browser_smoke.cjs`。`YODAKA_URL` で対象URL、`YODAKA_CHROMIUM` でChromiumの実行ファイルを指定でき、専用の一時ブラウザ内で通しプレイ（4回のセッションで謎を開く・向き合う・言葉を留める／手放す）、言葉の取得時の選択、チュートリアルの効果、トラウマ込みのストレスによる外出制限、勇気の上限による分岐の封鎖、棚からの向き合いと強化を検証します。
