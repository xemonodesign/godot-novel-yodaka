# よだか — ことばの標本

Godot 4.6.2 製のノベルゲーム・プロトタイプ。2026-10-19更新。

**遊ぶ:** https://xemonodesign.github.io/godot-novel-yodaka/

## プロトの流れ（2026-10-19版）

1. **冒頭のカウンセリング**：台本「カウンセリング0（OP）」と「カウンセリング1（システムチュートリアル）」を収録。カウンセラーのみなとが法月よだかに「メンタル〇〇」アプリを渡し、3つの質問にそれぞれ3択で答えます。そのあと**第1回のセッション**に入り、言葉欄を埋める8つのトラウマから1つを選んで話します（下記）。
2. **どこに行くか選ぶ寄り道（MAP）**：母と夕飯・公園・喫茶店・すみかと昼ごはん・母と話す・家で休む、から1つ選び、その場所の会話を再生。会話を1行読むごとに **EXP が1** 溜まります。
3. **言葉をもらう**：会話中に言葉が出ると暗転し、**心に留める／手放す**を選びます。留めると空いている欄に置かれ、持っている間バフが効きます。手放すと言葉の価値ぶんの EXP になります（カードを売る感覚）。欄が空いていなければ、持っている言葉をどれか忘れて EXP に変え、新しい言葉を置きます。
4. **メインストーリー**：寄り道を規定回数（2・2・1・1回）こなすと本編 CHAPTER 1〜4 が解放されます。夜の画面はなくなり、1日の終わりに眠る効果（ストレス -4）が自動で入って翌朝へ進みます。
5. **カウンセリング（全4回）**：冒頭、CHAPTER 1 のあと、CHAPTER 3 のあと、CHAPTER 4 のあと（総括）。各回で下の欄からトラウマか言葉を選び、EXP を使って整理します。最後はカルテを見て終了（END OF PROTOTYPE）。

## トラウマと言葉欄

- 言葉欄は8枠。**最初はすべてトラウマで埋まっています。** トラウマは枠にある間ずっとデバフを出し続けます。
  - 履けなくなったバッシュ：勇気の上限 5
  - 半年の空白：ストレス 常時 +30（奥に、もっと重いものがいる）
  - 女子制服：キラキラの増加 ×0.5
  - 「どう扱えばいい？」の空気：自認の増加 ×0.5
  - 「カッコいい」だった頃：EXP の溜まり方 ×0.5
  - 鏡の中の知らない顔：自認 常時 -15（奥に、もっと重いものがいる）
  - 誰もいない朝7時：キラキラ 常時 -15
  - 立ち止まっている間に：ストレスの回復 ×0.5
- トラウマには**固さ**（100）があり、デバフの大きさは固さに比例します。固さ 0 で「ほどけて」枠が空きます。
- **話す**：1回のセッションで1つだけ、トラウマについてみなとと話せます。話すと「ほぐれて」向き合えるようになり、必要 EXP が法外な値（50,000〜300,000）から 200 分の 1（250〜1,500）に下がります。いちばん最初に話した1つだけは 20 EXP で向き合えます。
- **向き合う**：ほぐれたトラウマに、持っている言葉を最大2つ重ねて EXP を払うと、固さが 30 減ります（言葉の「ほぐし」ぶんが加算）。言葉の「必要 EXP 半減／10分の1」はこの支払いに効きます。向き合うたびにカウンセリングらしい会話が出ます。
- **奥のもの**：「半年の空白」と「鏡の中の知らない顔」は、固さが 50 を切ると下からもっと重いトラウマ（戻れない場所／名前のない気持ち）が出てきて枠を奪います。「奥のものを抑える」効果を持つ言葉（新しい自分・法月さんのせいじゃない）を重ねていれば出てきません。

## 言葉（カード）

- 10種類。各言葉は**手放した時の EXP（価値）**、**持っている間の効果**、**トラウマに重ねた時の効果**を持ち、カウンセリングで EXP を使うと Lv3 まで育ちます。育てるたびに「こういう意味だったのか」という掘り下げの一文が出て、効果が変わります。
- 例：「えらい」（母、第1週の寿司）は Lv1 で勇気 +1・必要 EXP ×0.9 とザコいですが、Lv3 で **1タップの EXP ×10**・必要 EXP ×0.2 になります。「幸せにする権利」は最初から必要 EXP 10分の1。「親しい友達」は EXP ×3〜×10。「無駄じゃなかった」は忘れた時の EXP ×5〜×20。
- 枠が足りないので、どれを留めてどれを手放すか、EXP をトラウマに使うか言葉を育てるかが悩みどころです。

## パラメータ

ストレス + 3種類（勇気・自認・キラキラ）の4つ。素の初期値は `[20, 35, 35, 35]` で、画面に出るのは**素の値にトラウマと言葉の効果を足した値**（上限・下限 0〜100、トラウマの上限があればそこまで）。開始時の表示は `[50, 5, 20, 20]`。

- **ストレス**：出かけると +5、本編の章が始まると +6、眠ると -4、「家で休む」で -15（回復はトラウマで半減）。表示値が 80 以上になると寄り道に出かけられません。
- **勇気**：CHAPTER 4「お姫様じゃなくてもいい」の選択に表示値 60 が必要。バッシュのトラウマが固いままだと上限 5 で届きません。
- **自認**：自分の捉え方への納得度という暫定指標。男女を数値の両端にはしていません。
- **キラキラ**：人前での輝き。

## 操作

- 画面をクリック、または Space / Enter：全文表示、もう一度で次の文章。
- 章・場所の切り替えの暗転、カルテ、トラウマがほどけた／奥から出てきた演出はクリック / タップで進みます。
- 言葉をもらった暗転：「心に留める」「手放す（EXP）」のどちらかを選び、結果を見てクリックで続行。欄が足りない時は忘れる言葉を選びます。
- MAP：行き先ボタンを選択。行った場所・まだ解放されていない場所・疲れて行けない場所は理由つきで無効になります。
- カウンセリングのセッション画面：下の欄をクリックして選択 → 右側で「この傷について、話す」「向き合う」「育てる」「忘れる」。「今日はここまで」で終了。
- 下の欄：セッション以外ではクリックすると、トラウマの内容とデバフ、言葉の効果と掘り下げを読み返せます。
- 「読み返す」で会話ログ、「文字速度」で表示速度、「カルテ」で数値の内訳・トラウマ・言葉・EXP を表示。
- 同じブラウザ・同じURLで自動保存（形式v5）。「つづきから」で再開します。以前の流れ（v4以前）の保存は読み込まず、「はじめから」を案内します。
- PC / 横向きの画面向けです。小さい画面では全体を縮小して表示します。

## 実装

- 中央揃えの文字送り、全文表示、AUTO、会話ログ、速度変更、自動保存。
- 8枠の言葉欄を画面下に常時表示。トラウマは棘のある暗い標本（固さで棘の数が変わる）、言葉は花と石の3D標本、育った言葉には結晶。
- 言葉の取得暗転に「留める／手放す」の選択、枠が足りない時の「忘れる」選択を追加。
- カウンセリングのセッション画面（メンタル〇〇）：みなととよだかの会話欄、選択中の項目の詳細、言葉の組み合わせと必要 EXP・固さの予告、向き合う／育てる／忘れる。
- トラウマがほどけた暗転と、奥から出てきた暗転。
- 数値の表示はすべて効果込みの値。カルテで素の値・補正・上限の内訳を表示。

元の台本はローカルに保持し、公開物にはゲームに必要な素材とデータを含めています。ゲームで使うシートの本文は `src/data/source_rows.json` に行単位でキャッシュし、元のXLSXがなくても `make import` と `make test` が動きます。トラウマの文章（説明・話す会話・向き合う会話）はプロトタイプ用に書き下ろしたもので `src/data/traumas.json` にあります。音声・BGMは未実装です。

## 開発

Godot 4.6.2 と同バージョンの Export Templates を使います。

```sh
make install
make run
make lint
make test
make web
make serve
```

`make serve` の後、http://localhost:8060 を開きます。Web出力は `build/web/`。HTMLをダブルクリックして開く方式では動きません。`make web` は生成済みの `src/data/scenario.json` を使用するので、公開リポジトリだけでもビルドできます。

### 台本・言葉・トラウマを変更する

1. 元のXLSX（メイン・断片集1・断片集2・カウンセリング）をプロジェクト直下に置きます。無い本は `src/data/source_rows.json` のキャッシュから読みます。
2. `src/data/word_marks.json` の `node`（シート別ID＋行番号）と `word`（原文内の文字列）を指定します。`value` は手放した時の EXP、`levels` は3段階の `cost`（育てるのに必要な EXP）・`insight`（掘り下げの一文）・`passive`（持っている間の効果）・`counsel`（重ねた時の効果）。
   - `passive` の種類：`stat`（数値 +n）、`gain`（増加 ×n）、`exp`（1タップの EXP ×n）、`release`（忘れた時の EXP ×n）。
   - `counsel` の種類：`cost`（必要 EXP ×n）、`soften`（ほぐし +n）、`calm`（奥のものを抑える）。
3. `src/data/traumas.json` にトラウマを定義します。`debuffs` の種類は `offset`（常時 ±n）、`cap`（上限 n）、`gain`（増加 ×n）、`exp`（EXP ×n）、`recovery`（ストレスの回復 ×n）。`base_cost` は話す前の必要 EXP、`deeper` は奥から出てくるトラウマの id、`talk` は話す時の5行、`soften` は向き合った時の会話（first / mid / resolved）、奥のトラウマには `deep: true` と `surface`（出てきた時の2行）。
4. `make import` でXLSXから `scenario.json` を再生成。使ったシートの本文がキャッシュにも書き戻されます。
5. `make test` → `make web`。

ストレスの出費・回復は `src/story_state.gd` の `OUTING_EFFECTS` `CHAPTER_EFFECTS` `SLEEP_EFFECTS`、休息の回復は `REST_LINES` 末尾の `effects`。周回の構成（寄り道の回数と章、章のあとにカウンセリングを入れるか）は `src/tools/import_scenario.py` の `ROUNDS`、EXP とトラウマの定数（枠数・1タップの EXP・最初の必要 EXP・話した時の割る数・ほぐしの基本量・奥のものが出る固さ・重ねられる言葉の数）は `RULES`、勇気の必要値は `COURAGE_GATE` で変更し、`make import` で反映します。

### 公開の更新

`gh-pages` ブランチのルートをGitHub Pagesの配信元にしています。

```sh
make web
git worktree add /tmp/yodaka-pages gh-pages
cp build/web/* /tmp/yodaka-pages/
touch /tmp/yodaka-pages/.nojekyll
git -C /tmp/yodaka-pages add .
git -C /tmp/yodaka-pages commit -m 'feat(web): update playable prototype'
git -C /tmp/yodaka-pages push origin gh-pages
```

既に作業ツリーがあればそのパスを再利用してください。ソース変更は `main` に通常どおりコミットします。

詳細は [構成](docs/architecture.md) と [素材・生成記録](docs/assets.md) を参照。

ブラウザ検証: Playwrightをインストールした環境で `node tests/browser_smoke.cjs`。`YODAKA_URL` で対象URL、`YODAKA_CHROMIUM` でChromiumの実行ファイルを指定でき、専用の一時ブラウザ内で通しプレイ（4回のセッション・言葉の留める／手放す・向き合う・育てる、約25分）・チュートリアルの効果・ストレスによる外出制限・勇気の分岐・セッションの向き合いを検証します。`YODAKA_QUICK=1` で通しプレイを飛ばし、個別の検証だけを数分で実行できます。スクリーンショットの再生成は `xvfb-run godot --path . --resolution 1280x800 --script tests/screenshots.gd`。
